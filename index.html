A full PDF editor for your web app. No licence fee.

Inkbar renders PDFs in the browser and lets people fill in forms, highlight text, discuss it in note threads and mark it for redaction. It's written in TypeScript, works with Vue, React, Svelte or no framework, and it's free under the MIT licence.

A few components and one stylesheet.

Wrap a viewport in a root and build toolbars from the controls you want: tools, undo and redo, pages and zoom. Each is its own component, so move it, drop it or add your own buttons beside it.

Review.tsx
import {
  InkRoot,
  InkViewport,
  InkThreadPopover,
} from '@inkbar/react'
import { assets } from 'virtual:inkbar-assets'
import '@inkbar/theme/theme.css'

import { Footer } from './Footer'
import { Toolbar } from './Toolbar'

export function Review({ url, id }: { url: string; id: string }) {
  return (
    <InkRoot src={{ url, key: id }} assets={assets}>
      <Toolbar />
      <InkViewport />
      <Footer />
      <InkThreadPopover />
    </InkRoot>
  )
}

Typed end to end

Annotations are plain typed objects with a published JSON Schema. Keep them in your own state or let Inkbar hold them. Undo and redo work either way.

Headless underneath

Vue, React and Svelte share one framework-free core. Without a framework, use createViewer and the same controls from @inkbar/core.

One coordinate system

Inkbar works in PDF points with the origin bottom-left. You store the same numbers the PDF uses.

It should look like your product, not ours.

Ship the default theme as it is, restyle it with CSS, or render the controls as your own components. If your page already defines tokens such as --primary and --radius, the theme uses them.

Use the default

One stylesheet styles the toolbars, popovers and pages, in light and dark.

import '@inkbar/theme/theme.css'

Restyle it with CSS

Every rule has zero specificity, so yours win without !important. Or set Inkbar's --ink-* tokens on a single toolbar or popover.

.ink-toolbar {
  --ink-surface: #0d1026;
  --ink-fg: #ffffff;
  --ink-accent: #e4ff4a;
  --ink-accent-fg: #0d1026;
  --ink-radius: 999px;
  border-radius: 999px;
}

Use your own components

Render the toolbar buttons as your own components. Each keeps its behaviour and its accessible name.

<InkToolbar>
  <InkUndo asChild>
    <YourButton icon="undo" />
  </InkUndo>
</InkToolbar>

What it does today.

Inkbar covers viewing, search, forms, signatures, highlights, note threads, drawing and redaction marks. Everything below works in every framework package and with no framework.

Viewing

Pages render on PDF.js with a selectable text layer. Fit to width or page, zoom from 10% to 800%, and scroll continuously or a page at a time. Only pages near the viewport are mounted.

Search

Press Ctrl/Cmd+F in the viewer and type. Every match highlights and the count updates as pages scan. doc.search hands your code the same matches, with where each one sits on the page.

Forms

Fill text fields, checkboxes, radio buttons, lists and signature fields. The form's own scripts calculate totals and check input, and your code reads and sets the values through doc.form.

Signatures

Draw a signature, type it in a handwriting font or upload a scan. Inkbar keeps it in the store you choose and places it on any page or in a signature field.

Highlights

With the Highlight tool on, select text and it is highlighted when you let go. From the keyboard, select text and press Enter.

Note threads

Pin a note to the page, then reply, edit and delete in a thread beside it.

Redaction marks

Mark selected text, or drag a box over any area. A mark records what to remove. Inkbar will remove the content once saving into the PDF ships.

Drawing

Draw freehand, add lines, arrows, rectangles, ellipses, stars and polygons, and type into text boxes. A freehand stroke that looks like a shape snaps into one.

Annotations as data

Export and import JSON with a published schema. Underline, strikeout, squiggly, ink, shapes, lines and text boxes from imported data display too, and the PDF's own annotations show as locked.

Undo and redo

History with grouped steps, whether Inkbar holds the annotations or your app does, and field edits undo too. Press Ctrl/Cmd+Z, or put the undo and redo buttons wherever your toolbar has room.

Keyboard and screen readers

Fill fields, highlight, add notes, and move, resize or delete marks from the keyboard, with labelled controls throughout. Area marks and freehand drawing need a pointer.
