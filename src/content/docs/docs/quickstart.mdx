Put a PDF on screen with the default toolbar. This page assumes a Vite project.

## 1. Install the packages

You need the core, the theme and the package for your framework. The packages share one version number.

<FrameworkSnippet show="install" />

## 2. Add the Vite plugin

PDF.js loads a worker, fonts and decoders at runtime. The plugin serves those files in development and copies them into your build.

```ts title="vite.config.ts"
import { inkbar } from '@inkbar/core/vite'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [inkbar()],
})
```

<Aside>
  On another bundler, pass your own asset URLs to the root. [Loading
  assets](/docs/loading-assets/) lists the files.
</Aside>

## 3. Mount the viewer
