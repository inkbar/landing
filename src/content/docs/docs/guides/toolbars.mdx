Inkbar has no fixed toolbar. You put `InkToolbar` wherever it fits your layout, fill it with the controls you need, and add your own buttons beside them. You can have as many toolbars as you like: the [Quickstart](/docs/quickstart/) puts the tools above the document and the page and zoom controls below it.

## Controls

| Component                    | What it does                                                                         |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `InkToolbar`                 | Groups its buttons into one Tab stop, with arrow keys between them. `label` names it |
| `InkToolButton`              | Sets the tool given as `tool`, pressed while that tool is active                     |
| `InkToolbarSeparator`        | Divides groups of controls in a toolbar                                              |
| `InkUndo`, `InkRedo`         | Undo and redo, disabled when there is nothing to undo or redo                        |
| `InkPrevPage`, `InkNextPage` | Previous and next page, disabled on the first and last page                          |
| `InkPageInput`               | The current page number, which the user can type into                                |
| `InkPageCount`               | "of N", the page count                                                               |
| `InkZoomIn`, `InkZoomOut`    | Zoom in or out a step                                                                |
| `InkZoomSelect`              | Fit width, fit page, and zoom levels from 50% to 400%                                |
| `InkSearchButton`            | Opens the find bar, pressed while it is open                                         |
| `InkFindBar`                 | The find bar itself. Place it inside `InkRoot`. See [Search](/docs/guides/search/)   |
| `InkCommand`                 | Runs a [plugin](/docs/guides/plugins/) command given as `id`                         |
| `InkIcon`                    | Draws an icon from `@inkbar/icons`, for your own buttons                             |

`tool` is one of `select-text`, `select`, `highlight`, `redact-area` and `note`. Their accessible names are Select text, Rectangle select, Highlight, Mark for redaction and Add note. Pass `label` to change one. To rename any other button, pass `aria-label` and `title`.

Put the controls inside an `InkToolbar`, anywhere inside `InkRoot`. Each one reads its state from that root. Undo and redo follow the root's history. History is on by default; in controlled mode, turn it on with `history`. The page number field and the zoom select keep their own Tab stops.

## Icons and labels

Every button shows an icon from [`@inkbar/icons`](https://www.npmjs.com/package/@inkbar/icons) until you give it your own content. The accessible name stays the same either way.

Install `@inkbar/icons` only if you want its icons on your own buttons. The controls bring their own. The [Icons](/docs/reference/icons/) reference lists all 13.

## Rendering your own element

`InkRoot`, `InkToolbar`, `InkToolButton`, `InkCommand`, `InkUndo`, `InkRedo`, `InkPrevPage`, `InkNextPage`, `InkZoomIn` and `InkZoomOut` can render your own element in place of theirs, such as a button from your design system. In React, pass `asChild`. In Vue, pass `as-child`. In Svelte, use the `child` snippet and spread the `props` it gives you. The control keeps its behaviour and accessible name.

## Without a framework

`@inkbar/core/dom` has the same controls as functions for a [`createViewer`](/docs/frameworks/plain-dom/#the-whole-viewer) viewer: `createToolbar`, `createToolButton`, `createToolbarSeparator`, `createUndo`, `createRedo`, `createPrevPage`, `createNextPage`, `createPageInput`, `createPageCount`, `createZoomIn`, `createZoomOut`, `createZoomSelect`, `createSearchButton`, `createFindBar`, `createCommandButton` and `createIcon`.

## Styling

The theme gives a toolbar a background and padding, and styles the controls in it. You decide where the toolbar sits and what separates it from the document. Set `--ink-control-size` on a toolbar to change the height of its buttons, fields and zoom select (default `2.25rem`), and `--ink-icon-size` to change the size of their icons (default `1.125rem`):

```css
.my-page-bar {
  --ink-control-size: 2rem;
  --ink-icon-size: 1rem;
  border-top: 1px solid var(--border);
}
```

A tool button carries `data-tool` and `data-state="on|off"`, so `[data-tool="highlight"][data-state="on"]` targets the active highlight tool.
