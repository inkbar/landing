Quickstart

Put a PDF on screen with tools above it and page and zoom controls below. This page assumes a Vite project.

1. Install the packages

Section titled “1. Install the packages”

You need the core, the theme and the package for your framework. The packages share one version number.

  • Vue
  • React
  • Svelte

2. Add the Vite plugin

Section titled “2. Add the Vite plugin”

PDF.js loads a worker, fonts and decoders at runtime. The plugin serves those files in development and copies them into your build. It works with Vite 6 or later.

Note

On another bundler, pass your own asset URLs to the root. Loading assets lists the files.

3. Mount the viewer

Section titled “3. Mount the viewer”

Wrap the viewport in a root. Put a toolbar of tools, undo and redo above it and a page and zoom bar below, then add the popover for notes.

  • Vue
  • React
  • Svelte

The viewer fills its parent, so give the parent a height. Without one, the document has no room to scroll. Each control is its own component: drop the ones you don’t need, move them, or add your own buttons. Toolbars covers them.

Inkbar keeps the annotations itself here, with undo and redo. To hold them in your own state, read Controlled mode. Annotations live in memory until you save them: Annotations shows how to store them as JSON.
