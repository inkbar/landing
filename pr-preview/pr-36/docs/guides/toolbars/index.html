Toolbars

Inkbar has no fixed toolbar. You put InkToolbar wherever it fits your layout, fill it with the controls you need, and add your own buttons beside them. You can have as many toolbars as you like: the Quickstart puts the tools above the document and the page and zoom controls below it.

Controls

Section titled “Controls”
Component What it does
InkToolbar Groups its buttons into one Tab stop, with arrow keys between them. label names it
InkToolButton Sets the tool given as tool, pressed while that tool is active
InkToolbarSeparator Divides groups of controls in a toolbar
InkToolbarButton Your own button, in the toolbar’s arrow-key order. See Your own buttons
InkUndo, InkRedo Undo and redo, disabled when there is nothing to undo or redo
InkDownloadButton Downloads the open PDF. filename names the file
InkPrintButton Prints the open PDF with the browser’s print dialog
InkPrevPage, InkNextPage Previous and next page, disabled on the first and last page
InkPageInput The current page number, which the user can type into
InkPageCount “of N”, the page count
InkZoomIn, InkZoomOut Zoom in or out a step
InkZoomSelect Fit width, fit page, and zoom levels from 50% to 400%
InkSearchButton Opens the find bar, pressed while it is open
InkFindBar The find bar itself. Place it inside InkRoot. See Search
InkHighlightMenu Turns on the highlight tool, and picks highlight, underline, strikethrough or squiggly and the markup colour
InkShapeMenu Turns on the shape tool, and picks the kind. See Drawing
InkLineStyleMenu Line weight, solid or dashed, and arrowheads for the active tool or the selection
InkColorMenu The border, fill or textColor colour, given as property
InkTextStyleMenu A text box’s font, size, colour, bold, italic, underline and alignment
InkSignatureMenu Sign with the chosen signature, or pick or create one. See Signatures
InkCommand Runs a plugin command given as id
InkIcon Draws an icon from @inkbar/icons, for your own buttons

tool is select-text, select, or one of the creation tools you pass to the root (see Choosing tools). The first two are named Select text and Rectangle select. Pass label to change a tool button’s name. To rename any other button, pass aria-label and title.

Put the controls inside an InkToolbar, anywhere inside InkRoot. Each one reads its state from that root. Undo and redo follow the root’s history. History is on by default; in controlled mode, turn it on with history. The page number field and the zoom select keep their own Tab stops.

Ctrl or Cmd with Z undoes, and Ctrl or Cmd with Shift and Z, or Ctrl with Y, redoes. Both work on every platform. The keys do what InkUndo and InkRedo do, from anywhere inside InkRoot, toolbars included. In a text field, a select or editable content, they act on that element instead.

Ctrl or Cmd with P prints the PDF, and Ctrl or Cmd with S downloads it, from anywhere inside InkRoot once the document is ready. Outside the viewer the browser keeps them. The download takes the opened file’s name, or the last part of its URL, or document.pdf. Printing opens the browser’s print dialog for the PDF itself, so text stays sharp; on iOS the PDF opens in a new tab, where its own print is. Until saving into the PDF ships, both give the file as it was opened, without this session’s annotations.

Choosing tools

Section titled “Choosing tools”

select-text and select are always there. Every creation tool is opt-in: import its factory from @inkbar/core/dom and pass it to InkRoot as tools. Only the tools you import end up in your bundle.

Factory Tool Button name
highlightTool() highlight Highlight
redactAreaTool() redact-area Mark for redaction
sketchTool() sketch Sketch
drawTool() draw Draw
shapeTool() shape Shape
freetextTool() freetext Text box
signatureTool() signature Signature
noteTool() note Add note

Pass the tools your toolbar offers:

  • Vue
  • React
  • Svelte
  • Plain DOM

To offer every tool, pass allTools(), which returns a fresh instance of each of the eight:

A button for a tool you did not pass renders disabled and hidden. InkHighlightMenu, InkShapeMenu and InkSignatureMenu render nothing without their tool. Each logs an InkError('UnknownTool') to the console once. If the active tool leaves tools, the viewer switches to select-text and reports it through onToolChange (update:tool in Vue). A plugin’s tools join the viewer’s on their own.

Your own buttons

Section titled “Your own buttons”

InkToolbarButton is a button of your own inside an InkToolbar. It joins the toolbar’s arrow-key focus and takes the theme’s toolbar button styles. What it shows and does is up to you.

  • Vue
  • React
  • Svelte
  • Plain DOM

Button attributes such as aria-label, and listeners, pass through to the button. It takes as-child and disabled.

It takes the props of a <button>, with type="button" by default, and asChild.

It takes the attributes of a <button> and a child snippet.

No wrapper is needed. createToolbar() gives any <button> you append the same arrow-key focus, and the theme styles it like the toolbar’s own buttons.

InkIcon (createIcon in plain DOM) draws an @inkbar/icons icon on such a button, as the next section shows.

Icons and labels

Section titled “Icons and labels”

Every button shows an icon from @inkbar/icons until you give it your own content. The accessible name stays the same either way. This bar goes inside an InkRoot whose tools include redactAreaTool().

  • Vue
  • React
  • Svelte

Install @inkbar/icons only if you want its icons on your own buttons. The controls bring their own. The Icons reference lists all 13.

Rendering your own element

Section titled “Rendering your own element”

InkRoot, InkToolbar, InkToolButton, InkToolbarButton, InkCommand, InkUndo, InkRedo, InkDownloadButton, InkPrintButton, InkPrevPage, InkNextPage, InkZoomIn and InkZoomOut can render your own element in place of theirs, such as a button from your design system. In React, pass asChild. In Vue, pass as-child. In Svelte, use the child snippet and spread the props it gives you. The control keeps its behaviour and accessible name.

Without a framework

Section titled “Without a framework”

@inkbar/core/dom has the same controls as functions for a createViewer viewer: createToolbar, createToolButton, createToolbarSeparator, createUndo, createRedo, createDownloadButton, createPrintButton, createPrevPage, createNextPage, createPageInput, createPageCount, createZoomIn, createZoomOut, createZoomSelect, createSearchButton, createFindBar, createHighlightMenu, createShapeMenu, createLineStyleMenu, createColorMenu, createTextStyleMenu, createSignatureMenu, createCommandButton and createIcon. A <button> you append to createToolbar() joins its arrow-key order with no wrapper.

Styling

Section titled “Styling”

The theme gives a toolbar a background and padding, and styles the controls in it. You decide where the toolbar sits and what separates it from the document. Set --ink-control-size on a toolbar to change the height of its buttons, fields and zoom select (default 2.25rem), and --ink-icon-size to change the size of their icons (default 1.125rem):

A tool button carries data-tool and data-state="on|off", so [data-tool="highlight"][data-state="on"] targets the active highlight tool.
