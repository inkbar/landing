A full PDF editor for your web app. No licence fee.

Inkbar renders PDFs in the browser and lets people highlight text, discuss it in note threads and mark it for redaction. It's written in TypeScript, works with Vue, React, Svelte or no framework, and it's free under the MIT licence.

A few components and one stylesheet.

Wrap a viewport in a root and build the toolbar from the controls you want: tools, undo and redo, pages and zoom. Each is its own component, so move it, drop it or put your own buttons beside it.

Typed end to end

Annotations are plain typed objects with a published JSON Schema. Keep them in your own state and backend, or let Inkbar hold them with undo and redo.

Headless underneath

The components are unstyled primitives on a framework-free core, which the Vue, React and Svelte packages share. With no framework, one call tocreateViewer mounts the whole viewer.

One coordinate system

Inkbar works in PDF points with the origin bottom-left. You store the same numbers that go in the file.

Review.tsx
import {
  InkRoot,
  InkViewport,
  InkToolbar,
  InkToolButton,
  InkToolbarSeparator,
  InkUndo,
  InkRedo,
  InkPrevPage,
  InkPageInput,
  InkPageCount,
  InkNextPage,
  InkZoomSelect,
  InkNotePopover,
  InkSuggestionCard,
} from '@inkbar/react'
import { assets } from 'virtual:inkbar-assets'
import '@inkbar/theme/theme.css'

export function Review({ url, id }: { url: string; id: string }) {
  return (
    <InkRoot src={{ url, key: id }} assets={assets}>
      <InkToolbar>
        <InkToolButton tool="select" />
        <InkToolButton tool="highlight" />
        <InkToolButton tool="redact-area" />
        <InkToolButton tool="note" />
        <InkToolbarSeparator />
        <InkUndo />
        <InkRedo />
      </InkToolbar>
      <InkViewport />
      <InkToolbar label="Page and zoom">
        <InkPrevPage />
        <InkPageInput />
        <InkPageCount />
        <InkNextPage />
        <InkZoomSelect />
      </InkToolbar>
      <InkNotePopover />
      <InkSuggestionCard />
    </InkRoot>
  )
}

It should look like your product, not ours.

You can ship the default theme as it is. If you'd rather not, restyle it with CSS or render the controls as your own components.

Use the default

Import the theme and the toolbars, popovers and pages get a finished look, in light and dark modes.

import '@inkbar/theme/theme.css'

Restyle it with CSS

The theme's rules have zero specificity and sit in one cascade layer, so your CSS overrides them without !important. If your page defines tokens such as --primary and --radius, the theme uses them. To restyle one part, set Inkbar's own tokens on it, as this toolbar does.

@layer inkbar, utilities;

.ink-toolbar {
  --ink-surface: #0d1026;
  --ink-fg: #ffffff;
  --ink-accent: #e4ff4a;
  --ink-accent-fg: #0d1026;
  --ink-radius: 999px;
  border-radius: 999px;
}

Rebuild it in your design system

Render any control as your own button with asChild, or wire your own to the hooks for tools, zoom, pages and history.

<InkToolbar>
  <InkUndo asChild>
    <YourButton icon="undo" />
  </InkUndo>
</InkToolbar>

What it does today.

Inkbar covers reading, review and redaction marking. Everything below works in every framework package and with no framework.

Viewing

Pages render on PDF.js with a selectable text layer. Fit to width or page, zoom from 50% to 400%, and scroll continuously or a page at a time. Only pages near the viewport are mounted.

Highlights

Select text and highlight it with a click or the Enter key. The mark follows the text lines it covers.

Note threads

Pin a note to the page, then reply, edit and delete in a thread beside it.

Redaction marks

Mark selected text, or drag a box over any area. A mark records what to remove. Removing it from the file comes with saving into the PDF.

Suggested redactions

Pass in matches from your own detector. Each one shows its reason and confidence, and nothing counts until someone accepts it.

Annotations as data

Export and import JSON with a published schema. Underline, strikeout, ink, shapes and lines from imported data display too, and the PDF's own annotations show as locked.

Undo and redo

History with grouped steps, whether Inkbar holds the annotations or your app does. Put the undo and redo buttons wherever your toolbar has room.

Keyboard and screen readers

Highlight, add notes, and move, resize or delete marks from the keyboard, with labelled controls throughout. Drawing an area mark still needs a pointer.

On the way

  • Search across the document
  • Drawing tools for ink, shapes, lines and text boxes
  • Filling form fields
  • Saving annotations and applied redactions into the PDF

A line item you get to renew delete.

Most PDF SDK vendors sell an annual contract and name the price after a sales call. Inkbar is MIT licensed, so your team installs it from npm and starts building. The paid SDKs still cover more ground, such as forms and saving into the file. If your users need to read, mark up and review documents, Inkbar does that today.

Free for commercial use. Use it and change it inside a product you sell.

Nothing to procure. You sign no contract and manage no licence keys.

No lock-in. The source is public, and Inkbar renders documents in the browser without sending them to us.
