A few components and one stylesheet.

Wrap a viewport in a root, drop in the default toolbar, and you have a working editor. Take the toolbar out again when you want your own.

Typed end to end

Annotations are plain typed objects. Keep them in your own state, or let Inkbar hold them with undo and redo.

Headless underneath

The components are unstyled primitives on a framework-free core, which the Vue, React and Svelte packages share.

One coordinate system

Inkbar works in PDF points with the origin bottom-left. You store the same numbers that go in the file.

Review.tsx
import {
  InkRoot,
  InkViewport,
  DefaultToolbar,
  InkNotePopover,
} from '@inkbar/react'
import { assets } from 'virtual:inkbar-assets'
import '@inkbar/theme/theme.css'

export function Review({ url, id }: { url: string; id: string }) {
  return (
    <InkRoot src={{ url, key: id }} assets={assets}>
      <DefaultToolbar />
      <InkViewport />
      <InkNotePopover />
    </InkRoot>
  )
}

It should look like your product, not ours.

You can ship the default UI as it is. If you'd rather not, restyle it with CSS or replace it with your own components.

Use the default

Import the theme and you get a toolbar, popovers, and light and dark modes.

import '@inkbar/theme/theme.css'

Restyle it with CSS

The theme's rules have zero specificity and sit in one cascade layer, so your CSS overrides them without !important. If your page defines tokens such as --primary and --radius, the theme uses them.

@layer inkbar, utilities;

:root {
  --primary: #0d1026;
  --radius: 999px;
  --ink-highlight: #e4ff4a;
}

Rebuild it in your design system

Leave out the default toolbar and wire your own buttons to the state it uses.

<InkRoot src={src} assets={assets}>
  <YourToolbar />
  <InkViewport />
</InkRoot>

What the paid SDKs do, in the free one.

Viewing

Rendering built on PDF.js, with zoom, page navigation, text selection and search.

Text markup

Highlight, underline, strikeout and squiggly, anchored to the text they mark.

Notes and threads

Pin a note to the page and reply to it, so the review happens on the document.

Drawing and shapes

Freehand ink, rectangles, ellipses, lines, arrows and text boxes.

Redaction

Mark text and regions for redaction, then review each mark before you apply it.

Forms

Read and fill form fields in the viewer.

Undo and redo

Built-in history, whether Inkbar holds the annotations or your app does.

Accessible by default

Keyboard access and screen-reader labels across the default UI.
